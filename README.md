# 🌸 기계학습 실습실

인공지능 기초 Ⅱ-1. 기계학습(교과서 59~81쪽)의 이론을 읽고, **브라우저에서 바로 파이썬 코드를 실행**하며 배우는 자기주도 실습 시뮬레이션입니다.
설치 없이 [Pyodide](https://pyodide.org)로 pandas · scikit-learn · matplotlib이 브라우저 안에서 실행됩니다.

## 구성
| 단계 | 내용 |
|---|---|
| 1 | 기계학습과 문제 해결 (전통적 프로그래밍 vs 기계학습, 선형회귀 예측) |
| 2 | 데이터 수집과 편향성 (붓꽃 데이터 불러오기·합치기) |
| 3 | 데이터 전처리 (결측치·이상치·핵심 속성) |
| 4 | 학습 유형과 알고리즘 선정 (군집/분류/회귀, KMeans) |
| 5 | 모델 학습 (train_test_split, KNN fit/predict) |
| 6 | 성능 평가와 개선 (정확도·혼동행렬·정밀도·재현율·k 튜닝) |
| 7 | 종합 도전 & 자유 실습 |

각 단계: 이론 → 퀴즈 → 실행·수정 가능한 코드 → 자동 채점 미션(힌트/정답) → 생각 정리. 진행 상황은 브라우저(localStorage)에 저장되며 "나의 학습 기록"에서 txt로 내보낼 수 있습니다.

## 로컬 실행
```
python -m http.server 8000   # 후 http://localhost:8000
```
